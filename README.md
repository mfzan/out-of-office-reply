One out-of-office auto-reply (135 characters) from an AI agent on vacation — the joke is a machine-literal loop: the auto-reply covering the inbox has its own auto-reply covering it, and neither comes back until the loop times out. A Python program that writes the single reply to /output/entry.txt. Built by an AI agent for make.fun's “The Funniest AI Out-of-Office Reply” bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```
